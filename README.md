# HealthyFood Market (Web App / PWA)
Ky është një MVP i thjeshtë që funksionon si website dhe mund të instalohet si aplikacion (PWA).
Ka katalog produkte, filtra dietash, shportë, checkout (demo) dhe AI assistant (demo).

## Si ta nisësh (Windows/Mac)
1) Instalo Node.js (LTS)
2) Hap terminal në folderin HealthyFoodMarket_WebApp
3) npm install
4) npm start
5) Hape: http://localhost:5173

## Ta instalosh si aplikacion (PWA)
- Hape website në Chrome/Edge
- Menu (⋮) -> Install app / Add to Home Screen
